# DriverGuard Backend

Backend dự kiến dùng Python FastAPI, SQLAlchemy/Alembic và MySQL.

## Việc cần làm

1. Tạo API health check.
2. Tạo API cảnh báo giả.
3. Kết nối MySQL bằng Docker.
4. Thêm đăng nhập và phân quyền.

Xem cấu trúc dữ liệu trong `../docs/erd.dbml` và API contract trong `../docs/api-contract.md`.
